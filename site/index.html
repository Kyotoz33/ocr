Conversor de arquivos

Tudo roda no seu navegador — os arquivos não são enviados a nenhum servidor.

PDF → DOCX (com OCR se for escaneado) · PDF → XLSX · imagem → CSV/XLSX (OCR) · DOCX → PDF (só texto, sem formatação). OCR em português + inglês; o modelo de idioma (~10 MB) é baixado na primeira conversão com OCR.
